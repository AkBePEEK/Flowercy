# Инструкция по интеграции мобильного приложения с AI Florist API

Этот документ содержит инструкции по обновлению мобильного приложения для использования генерации изображений через **Stable Diffusion** вместо заглушек Pillow.

## 1. Настройка запроса на генерацию
Чтобы мобильное приложение гарантированно получало изображение, сгенерированное нейросетью, необходимо обновить тело POST-запроса к эндпоинту `/generate-image`.

**Endpoint:** `POST /generate-image`

**Обновленный JSON-объект:**
```json
{
  "flowers": ["название_цветка1", "название_цветка2"],
  "colors": ["цвет1", "цвет2"],
  "mood": "настроение",
  "style": "стиль",
  "occasion": "событие",
  "force_gen": true
}
```
> **Важно:** Параметр `"force_gen": true` отключает поиск по каталогу и принудительно запускает Stable Diffusion на GPU сервера.

## 2. Обработка ответа
API возвращает изображение в двух форматах. Мобильное приложение должно использовать `image_base64` для мгновенного отображения.

**Формат ответа:**
```json
{
  "image_base64": "iVBORw0KGgoAAAANSUhEUgAAAgAAAAIAB...",
  "image_path": "outputs/bouquet_20260602_153000.png",
  "prompt_used": "...",
  "generated_at": "..."
}
```

**Для Flutter (пример):**
```dart
Image.memory(base64Decode(response['image_base64']))
```

## 3. Оптимизация на стороне сервера (уже выполнено)
Для того чтобы приложение не "зависало" на этапе Pillow:
1.  **CUDA (GPU)**: Сервер настроен на использование видеокарты (библиотека `torch` версии `+cu121`).
2.  **Python 3.10**: Окружение пересобрано на стабильной версии для поддержки драйверов NVIDIA.
3.  **Автоматический выбор**: Если видеокарта по какой-то причине недоступна, сервер автоматически переключится на CPU, но теперь Stable Diffusion включен по умолчанию.

## 4. Как проверить интеграцию
1. Запустите сервер: `.\venv\Scripts\python.exe -m uvicorn api:app --reload --host 0.0.0.0`
2. Убедитесь, что мобильное приложение стучится по правильному IP адресу сервера.
3. При запросе с `force_gen: true` в консоли сервера должно появиться: `🚀 Using Stable Diffusion on cuda...`
